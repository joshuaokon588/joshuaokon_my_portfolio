# Joshua Okon — Professional Portfolio

A six-page-style single-page portfolio experience with six navigable sections:
Home, About, Services, Projects, Blogs and Contact.

## Design
- Soft cream background
- Dark charcoal typography
- Muted gold accents
- Editorial / premium portfolio styling
- Continuous yellow sponsor marquee
- Responsive navigation
- Mobile menu
- Page-style navigation without reloading
- Animated entrance and hover effects

## Sponsor marquee
The ribbon includes visual text marks for:
Visa, Mastercard, Airtel Money, MTN MoMo, Bank Transfer, PayPal and an Open for Sponsorships handshake.

These are presentation placeholders, not official brand logo assets. Replace them with approved logo files if you have permission to use official logos.

## Files
- index.html
- style.css
- script.js
- assets/images/README.txt

## Run
Open `index.html` with VS Code Live Server.

## Contact form
The form is currently a frontend demo. Connect it to Formspree, Netlify Forms, EmailJS or your own backend before production.

## Notes
The portfolio intentionally uses a single HTML file with six navigable page sections so it is easy to maintain and deploy on GitHub Pages. If you need six physically separate HTML files later, the same sections can be split into `home.html`, `about.html`, `services.html`, `projects.html`, `blogs.html` and `contact.html`.
